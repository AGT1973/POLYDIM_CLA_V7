### ***Fundamento verificado**

***SORM existe como método formal. El preprint de la Universidad de Rostock (2012) documenta el algoritmo: "Permute the rows of I to avoid small cycles. Then the singular values as well as the absolute values of the eigenvalues of the resulting matrix all are 1. ***import numpy as np**

```
***from scipy.sparse import csr\_matrix**


***class SORMReservoir:**

    ***def \_\_init\_\_(self, N, nnz\_per\_row=20, depth=3):**

        ***self.N = N**

        ***self.alpha = 0.25**

        ***self.state = np.random.randn(N)**

        ***self.state /= np.linalg.norm(self.state)**

        ***self.W = self.\_build\_sorm(N, nnz\_per\_row, depth)**


    ***def \_build\_sorm(self, N, nnz\_per\_row, depth):**

        ***"""Construye W = producto de depth matrices de Givens dispersas.**

        ***Cada Givens rota un par (i,j) cercanos. nnz por fila es 2·depth."""**

        ***rows, cols, data = \[\], \[\], \[\]**

        ***for d in range(depth):**

            ***stride = 2\*\*d**

            ***for i in range(0, N - stride, 2\*stride):**

                ***j = i + stride**

                ***theta = np.random.uniform(0, 2\*np.pi)**

                ***c, s = np.cos(theta), np.sin(theta)**

                ***rows.extend(\[i, i, j, j\])**

                ***cols.extend(\[i, j, i, j\])**

                ***data.extend(\[c, -s, s, c\])**

        ***W = csr\_matrix((data, (rows, cols)), shape=(N, N))**

        ***return W**


    ***def step(self, u\_in):**

        ***\# O(N · nnz\_per\_row) = O(20N) = O(N)**

        ***a = self.W @ self.state**

        ***new\_state = (1.0 - self.alpha) \* self.state + self.alpha \* np.tanh(a + u\_in)**

        ***norm = np.linalg.norm(new\_state)**

        ***if norm \> 1e-15:**

            ***self.state = new\_state / norm**

        ***return self.state**
```

```
    ***if np.isnan(h).any() or np.isinf(h).any():**

        ***raise ValueError("Input must be finite")**

    ***norm\_h = np.linalg.norm(h)**

    ***if norm\_h == 0.0:**

        ***e1 = np.zeros\_like(h); e1\[0\] = 1.0**

        ***return e1, -np.inf**

    ***if not np.isfinite(norm\_h):**

        ***h\_max = np.max(np.abs(h))**

        ***h\_scaled = h / h\_max**

        ***norm\_scaled = np.linalg.norm(h\_scaled)**

        ***u = h\_scaled / norm\_scaled**

        ***return u, np.log(h\_max) + np.log(norm\_scaled)**

    ***u /= np.linalg.norm(u)**

    ***return u, float(np.log(norm\_h))**


***def decode(self, u, r):**

    ***if np.isneginf(r):**

        ***return np.zeros\_like(u)**

    ***return np.exp(r) \* u**


***def log\_map(self, u, w):**

    ***"""Log\_u(w) con Taylor para theta pequeño y error en cut locus."""**

    ***inner = np.clip(np.dot(u, w), -1.0, 1.0)**

    ***theta = np.arccos(inner)**

    ***if theta \< 1e-7:**

        ***return w - u  \# Taylor: Log\_u(w) ≈ w - u**

    ***if np.pi - theta \< 1e-7:**

        ***raise ValueError("Near cut locus: undefined")**

    ***return (theta / np.sin(theta)) \* (w - np.cos(theta) \* u)**
```
